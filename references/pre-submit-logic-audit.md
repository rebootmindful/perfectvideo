# 出稿前逻辑审核（Pre-Submit Logic Audit · 强制闸门）

> **触发时机**：`prompts.primary`（及 lang_en）编译完成之后、提交给模型/调生成 API **之前**。
> **视角**：导演（合同自洽）+ 观众（画面可读、不搞笑）。
> **铁律**：任一 **FAIL** → 禁止提交、禁止调生成 API，先修复剧本；修复后重审，全 PASS 才放行。
> **渊源**：2026-08-09 江南·共生觉醒 fast 版实测教训——剧本内部自相矛盾（一镜到底却写 3 处 cuts、机位瞬移、情绪反转无支撑、藤蔓触水却遮天），模型忠实执行后画面跳变/断裂/搞笑。
> **配套**：`compile-modes.md` §6（提交完整性铁律）· `diagnose-repair.md`（脚本层 7 维评分）· `post-shot-review.md`（生成后执行度对账）。本审核管"提交前"，post-shot 管"生成后"。
> **⚠️ 维度字母不混用**：本文件的 A–G（合同/空间/情绪/尺度/声画/密度/一次看懂）与 `diagnose-repair.md` 的 A–G（材质/事件/光向/收尾/类型/抽象词/镜头主权）**编号相同但含义完全不同**——两者是不同闸门，评分卡各用各的，禁止交叉引用维度字母。

---

## 1. 七维审核清单（六维合同自洽 + 第 7 维观众试映）

逐条检查提交稿。**每条必须给出 PASS / FAIL + 依据**（引时间码/原句），FAIL 给修复指令。

### 维度 A · 合同一致性（自相矛盾 = 最大事故源）
- [ ] 模式声明与正文一致：宣称 `single continuous take / no cuts` 的，15-BEAT 里**不得出现** `camera cuts / cut to / close-up 切换 / 景别跳变`；
- [ ] 一镜到底时，机位段数、景别变化必须在**单个连续镜头物理可行**范围（超广角无法 4 秒内做 3 次景别跳变）；
- [ ] 若需要切换 → **改模式**（A+ MultiClip 逐拍 / B MultiShot / C 链），不许"既一镜又切"。
- **典型 FAIL**：`CAMERA CHAIN: no cuts` + `0:05-0:06 Camera cuts to close-up`。

### 维度 B · 空间拓扑（机位链可走通性）
- [ ] 画出机位轨迹：每个时刻镜头**物理位置**可连续到达（如：船后 → 绕船侧 → 沿河升 → 进裂缝 → 穿出 → 回船），无瞬移；
- [ ] 同一机位动作（如"从船头升起"）**不得重复触发两次**而中间无回落交代；
- [ ] 进入/穿出大物体（巨物/建筑/裂缝）时，出口与下一画面的空间关系有定义；
- [ ] 与 ENVIRONMENT LOCK 的空间尺度一致（见维度 D）。
- **典型 FAIL**：0:00-0:03 机位在船后，0:07 突然"船头升起"；"从船头升起"在 0:07 与 0:11 各出现一次。

### 维度 C · 情绪因果（人物动机链）
- [ ] 每个 beat 主角的反应**由上一 beat 的可见事件驱动**，无无来由情绪；
- [ ] 情绪方向自洽：正面反馈后不无理由转负面（如"被回应/被点亮"后不能无端"更怕"，除非写清"回应过猛吓到她"的可见依据）；
- [ ] 状态改变不可逆：下一拍不能复位（沿用 15 拍骨架铁律）；
- [ ] 恐惧/决断/共生等关键转折点，都有**可见触发事件**（光纹骤亮/船被推/声音轰鸣）。
- **典型 FAIL**：0:04 恐惧站起 → 0:05-0:07 被回应+灯笼因她点亮（正面）→ 0:07 却"afraid to play"。

### 维度 D · 物理尺度（物体比例与距离）
- [ ] 物体相对大小自洽：如"藤蔓触到水面" → 巨物底面不可能同时"覆盖大半天空"（二选一：高悬则光流触水 / 低垂则不遮天）；
- [ ] 移动速度合理：15s 内主角/船/镜头的位移与"同一镜头"的时间流速匹配（不能 15s 漂过桥+灯笼+到巨物下）；
- [ ] 大物体内部↔外部、远景↔特写的比例关系一致；
- [ ] 负面词中禁的东西（瞬移/穿模）不能在剧本正文出现。
- **典型 FAIL**：0:10-0:11 藤蔓"touch the water surface" vs ENVIRONMENT LOCK "covering most of the sky"。

### 维度 E · 声画对齐（三轨与动作逻辑）
- [ ] 声锚与动作因果关系匹配：单音 ≠ "tone rises 成旋律"；无持续弹奏 ≠ "strings stop"；
- [ ] diegetic 声锚的时序参数（周期/渐起/停止）与 15-BEAT 动作对齐；
- [ ] 声画可分离：纯视觉去掉声音后，观众仍能读懂因果（**视觉因果 > 听觉因果**，弦音驱动的因果必须有可见响应步骤）；
- [ ] path.vo 旁白与画面信息不冲突（旁白不解释画面已在演的事）。
- **典型 FAIL**：0:04 只"拨响一根弦"，0:06-0:08 却写"tone rises"；0:08 写"strings stop"但 0:04 后一直悬指未弹。

### 维度 F · 密度控制（单切片事件负载）
- [ ] 15s 单镜头内**主事件 ≤5 个**（如：宁静 → 巨物现 → 回应 → 决断 → 共生），其余为视觉延续；
- [ ] 事件数 = 15-BEAT 数 + 机位段数 + 光变数 + 声锚数 + 情绪转折数；>5 即超载 → 要么砍、要么拆 A+ MultiClip 分段；
- [ ] 微动节拍/rack-focus 等细节是"主事件内的点缀"，不算独立主事件，但总指令密度需对模型执行粒度现实（fast 级模型尤其降载，见 `model-constraints.md` §8）。
- **典型 FAIL**：15 拍×独立动作 + 5 段机位 + 4 段光变 + 5 段声锚 + 3 次情绪转折全塞一条 15s。

## 2. 观众视角检查（搞笑风险 · 重大失误排查）

逐条对**提交稿终稿**做"观众读图"模拟：假想第一次看片，哪个画面会让人"噗"出来。

- [ ] **无瞬移**：任何物体/人物/镜头不得在两帧间无过渡换位；
- [ ] **无消失**：已出现的道具/人物/巨物在后续不得无故消失（除非有明确动作）；
- [ ] **无情绪反转**：无"刚被感动突然害怕/刚害怕突然大笑"式无支撑反转；
- [ ] **无尺度突变**：巨物/人物相对大小不得跳变（小船变巨轮/手指变石柱）；
- [ ] **无重复机位**：同一运镜动作不得原样出现两次（观众会觉得"卡带"）；
- [ ] **无诡异物理**：物体不穿模、不悬空无理由、不倒流（除非题材设定明确）；
- [ ] **无搞笑意象组合**：宏大主题下出现小丑式细节（如庄严肃穆场景里角色突然做滑稽动作）；
- [ ] **收尾符合情绪**：终场帧的构图/色调与主题情绪一致，不与中段戏剧冲突。

> 任一 ✓ 缺失 → 判定 FAIL，指出具体拍段与修复方案。

### 2.5 观众试映 · 第 7 维「一次看懂」（2026-08-09 新增）

> 导演自审（六维）防"合同矛盾"，本维补"模拟观众首次观看"：
> **遮住 prompt，只看 shotlist 时间码，能否复述故事？**

- [ ] **一次复述**：遮掉 prompt 只看 shotlist（t_in/t_out + visual + camera），能否讲出"谁 → 遇到什么 → 怎么变"？讲不出 → 信息断点，FAIL；
- [ ] **认知负载**：15s 内新信息点数 ≤ 5（每点 = 一个新对象/新状态/新关系）；超出 → 观众跟不上，砍或拆 A+；
- [ ] **无自指依赖**：观众不需要知道"导演意图/上一稿"才能看懂本镜（本镜内部自洽，跨镜信息靠显式承接）；
- [ ] **留白可懂**：悬念是"想知道后面"（可懂），不是"没看懂刚才"（失败）。

## 4. 与既有闸门的分工（不重复）

| 闸门 | 管什么 | 时机 |
|------|--------|------|
| 诊断 Pass（`diagnose-repair.md`） | 脚本质量 7 维（材质/事件/光向/收尾/类型承诺/无抽象词/镜头主权） | 锁档后、编译前 |
| 提交完整性（`compile-modes.md` §6） | 导演决策不蒸发（时间码/机位链/声锚/光相位/材质宪法 verbatim） | 编译时 |
| **出稿前逻辑审核（本文件）** | **合同自洽 + 空间可走 + 情绪有因 + 尺度一致 + 声画对齐 + 密度可控 + 观众不搞笑** | 编译后、**提交前** |
| 执行度对账（`post-shot-review.md`） | 生成后逐拍核对执行度（写拍改闭环） | 生成后 |

> 一句话：**诊断 Pass 管"写得好不好"，完整性管"丢没丢"，逻辑审核管"通不通、笑不笑"，对账管"做没做"。**
