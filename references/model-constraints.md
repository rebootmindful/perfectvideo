> 状态：**数值为行业通行上限 + 常见默认；发布前请在目标平台官方文档复核**（模型迭代快，本表给「安全默认」）。

**默认：** `model_clip_budget_s = 15` 是**安全假设**；若用户指定模型，按上表收窄（如 Runway → 10）。  
**惊艳四件套能力列：** 真声轨只在 native audio 模型（H3 / Kling 3.0）启用；其余模型退文字锚并标注「需宿主配音」。

## 2. 时长规则（双时长联动）

```text
target_edit_duration_s <= model_clip_budget_s → 模式 A（Single15）
target 2–3 × clip → 模式 B（MultiShot-in-one，同次 2–3 真切）
target > 3 × clip → 模式 C（NextShot Chain）
```

**禁止：** target 远超 model 却输出单条超长提示词。

## 6. 压缩预算（模型上下文参考）

- 视频模提示词建议 ≤ 800–1500 字（中文）；超长用 `compact` 编译  
- 静帧 still 提示词 ≤ 300–600 字（MJ 约 50–200 词）  
- **锁定域不可因压缩省略**：人物+衣帽+道具外观+环境 key_elements+材质要点
