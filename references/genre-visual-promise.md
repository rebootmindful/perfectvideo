# 类型视觉承诺库 · Genre Visual Promise

> **用途：** 保证"说到做到"——用户说了某个类型，Bible 必给该类型的**标志性视觉 set-piece**，否则就是"承诺不足"，观众觉得"假"。
> **移植自：** `movie-development-skill` 的「类型片场景模板库」精髓（"每个类型至少 5–8 个关键场景，否则承诺不足；先问观众为何继续看"）。
> **何时读：** 五步协议 ② 选架构后、③ 抽机制前，先查本库确认"这个题材的观众在等什么画面"。

---

## 0. 什么是"类型视觉承诺"

用户一句话往往带一个**隐含契约**：说"武侠"就是在承诺"轻功/剑气/衣袂"；说"赛博"就是在承诺"霓虹/雨夜/金属反射"。AI 视频最致命的不是细节少，是**承诺落空**——取了个武侠名却只给两个人对站，观众立刻出戏。

**硬规则：** Director's Bible 必须包含本库为该 genre 列出的**全部承诺镜头**（至少覆盖 3 类），缺一类就在诊断评分卡扣"类型承诺"分。

---

## 1. 类型 → 必给视觉 set-piece 映射

每类列出"该类型观众默认等待的标志性画面"。Bible 抽机制时**先过这一关**。

### 1.1 武侠 / 古装动作
- **轻功腾跃**：踏枝/踏峰/踏水借力腾空，衣袂贲张。
- **剑气/兵器光弧**：招式带可视能量轨迹，非单纯挥砍。
- **衣袂与发丝**：高速运动中绸带/长发向后流体贲张，构成动态美感。
- **峰林/竹林/客栈**：典型东方场景锚点为承诺景。
- **近身交击火花**：兵器相格迸火花或气浪，定格张力。
- **慢镜定格**：一招制敌或生死一线时的子弹时间。

### 1.2 赛博 / 科幻未来
- **霓虹雨夜**：湿地面反射霓虹，雨丝成光柱。
- **全息 UI / 数据流**：悬浮界面、符文、代码流附身。
- **金属反射与冷硬材质**：硬表面高光、非塑料。
- **义体 / 电路纹**：身体与机械共生痕迹（克制使用，防过度）。
- **冷调唯一暖点**：青蓝主调中一门灯/一处火花为焦点。

### 1.3 神话 / 史诗
- **宏大建制镜头**：天地/神域全景，体积光倾泻。
- **神力可视化**：金流/流体/光柱驱动万物。
- **悬浮 / 失重结构**：山石、圆环、岛屿浮于虚空。
- **仪式性静止**：主体微动、世界呼吸，对比能量爆发。

### 1.4 流体 / 抽象
- **统一材质语言**：全片共用一种流体语法，无材质边界（见机制库 2.4）。
- **连续材质转化**：动作后惯性引发材质演化（发化墨、衣连云）。
- **环境流体承担主运动**：人物微动，烟雾/水流为主要视觉驱动。

### 1.5 恐怖 / 惊悚
- **底光 / 顶光**：非自然光向制造不安。
- **遮挡与窥视**：长焦孤立、框架构图、不完全暴露。
- **静默突变**：长时间克制后单一冲击事件（禁频繁跳吓）。

### 1.6 自然 / 风光
- **大气透视**：远山雾化、层次递进。
- **天气情绪**：雾/雨/雪/光作为情绪载体。
- **时间相位**：晨昏光变或季相，构成叙事时间感。

## 2. 混合类型的承诺叠加（常见）

用户常给**混合类型**（如"赛博武林"），此时承诺是**交集而非并集**：

| 混合题材 | 必给承诺（叠加） |
|----------|------------------|
| 赛博武林 | 轻功腾跃 + 剑气光弧 + 霓虹雨夜/湿反射 + 金属冷硬 + 衣袂贲张 |
| 神话科幻 | 宏大建制 + 神力可视化 + 悬浮结构 + 冷硬材质 |
| 武侠恐怖 | 衣袂流体 + 长焦窥视 + 静默突变 + 底光 |

**要点：** 混合类型不能只取一边。说"赛博武林"却只有武侠皮、无霓虹金属，即"赛博承诺不足"。

## 3. 与本协议的衔接

- 五步 ② 选架构后，先查本库圈定"承诺镜头清单"。
- ③ 抽机制时，机制卡必须覆盖承诺清单（可一张卡服务多个承诺）。
- ④ 重组落地时，承诺镜头逐一落到可见事件。
- Diagnose pass（见 `diagnose-repair.md`）把"类型承诺"列为评分卡一项，缺则修复。

## 4. 用法示例（赛博武林峰林搏斗）

genre = 赛博武林（混合）→ 承诺清单：
1. 轻功踏峰腾空（武侠）
2. 剑气霓虹交错光弧（武侠+赛博）
3. 湿衣霓虹流光/冷金属反射（赛博）
4. 衣袂与发丝贲张（武侠）
5. 交击火花定格（武侠）
6. 峰林雾海建制（武侠场景锚点）

Bible 必须全部覆盖，否则诊断扣"类型承诺"分并补写。
