# 叙事主轴方法论（蒸馏自 movie-development-skill）

> **用途**：PerfectVideo 在「方向规划门禁（UG）」阶段，把模糊意图变成可選的 **故事方向**，
> 并在写任何提示词前让用户确认。随技能启动即加载，无需会话中临时去读外部 skill。
> **渊源**：`D:\skills\movie-development-skill`
> （结构A 故事线与类型 / 结构B 15拍写作手册 / 结构C 节奏分场与第三幕 / 高质量场景拆解案例库）。

---

## 1. 故事线公式（主角四问 · 强制卡）

**UG 门禁前置必填**（2026-08-09 起强制）：每个方向必须先把四问写满（每行 ≤1 句），
答不出 → 回 U0 追问"主角是谁、ta 卡在哪"，禁止带病出方向。

- **想做什么**（欲望 / 目标）
- **怕什么**（恐惧 / 代价）
- **被什么压**（压力 / 阻碍）
- **错信什么**（错误信念 → 弧光终点要打破它）

四问答出，主角就有"为什么动"，观众才看得懂意图；
答不出四问 = 场景堆砌而非人物驱动，方向选项会被打回。

## 2. 15 拍骨架（≤15s 短片）

**1 beat ≈ 1 秒**。每拍必须 **改变观众对主角 / 世界 / 关系的理解**，不能只是"好看"。
拍位功能（可裁剪，但骨架不能丢）：

```
开场(立世界+主角缺陷) → 主题 → 铺垫 → 催化(旧方法失效)
→ 犹豫 → 第二幕 → B故事 → 玩闹/游戏 → 中点(升级)
→ 反派加压 → 一无所有(旧自我破产) → 灵魂黑夜(承认错)
→ 第三幕 → 解决 → 终场(与开场视觉对照)
```

## 3. 开场↔终场视觉对照法则（show change, don't tell）

- 终场必须在 **视觉上** 与开场形成对照（色调 / 构图 / 状态 / 光向），
  让观众"看见改变"而非靠旁白解释。
- 例：冷蓝被囚 ↔ 暖金自由；孤立对峙 ↔ 共生流动；破碎 ↔ 完整；暗夜 ↔ 黎明。

## 4. 场景总公式（每拍 / 每镜为何存在）

```
目标 + 权力 + 信息差 + 冲突升级 + 转折 + 关系变化 + 状态改变（下一拍不能复位）
```

答不出"这一拍为何存在" → 删或改。这是给用户的提示词"意图层"。

## 5. 类型视觉承诺库（genre → 必给 set-piece）

混合类型时承诺堆叠（每类型至少 1 个标志性视觉）：

| 类型 | 必给视觉 set-piece |
|------|---------------------|
| 武侠 / 古风 | 轻功 / 剑气 / 峰林对决 / 水墨留白 |
| 赛博 / 科幻 | 霓虹雨夜 / 数据流 / 全息 / 机械义体 |
| 超级英雄 | 超能觉醒 / 城市天际 / 符号光 |
| 恐怖 | 暗角 / 呼吸雾 / 突然静默 |
| 爱情 | 微距触碰 / 暖光逆光 |
| 喜剧 | 夸张错位 / 快剪 |
| 纪录 / 自然 | 真实质感 / 长焦压缩 / 自然光 |

> Bible 未包含对应 set-piece → **"承诺不足"**，门禁时应向用户点明。

## 6. 可复用叙事弧模板（方向选项可直接套）

```
缺陷(错误信念) → 催化(旧方法失效) → 对手/压力升级
→ 一无所有(旧自我破产) → 灵魂黑夜(承认错误)
→ 新行动(主题真相) → 终场对照
```

## 7. 门禁怎么用（给 interface agent）

拿到 U0 意图后，用 §1–§6 生成 **2–3 个方向选项**，每个选项给 4 要素：

1. **故事主轴**（一句话：缺陷→催化→解决）
2. **开场↔终场视觉对照**（show change）
3. **生成策略**（见 `model-constraints.md` §8：模型 + 连贯性 + 预计成本）
4. **时长 / 格式**（Single15 / SinglePass / MultiShot / NextShot）

用户确认 1 个（或"换一个"）→ 才进 U1–U6 细化 →
U✅ 锁定 + 生成策略明示确认 → **才落提示词、才调生成**。

## 8. NextShot 方向生成法（3 追问 → 3 方向 · 2026-08-09 新增）

> **为什么 NextShot 也要给方向**：第一镜只是故事的一个切片，下一镜怎么续有无数可能。
> 若只听用户指挥场景，skill 就退化成"导演听命执行"。给 3 个**真实不同的推进方向**
> （非换皮），用户选一个，才锁场景 delta 走全链——与 FirstShot 的 UG 门禁同构。
> **约束**：NextShot 方向必须满足——材质宪法/人物锁/光相位/声锚**字符级继承**、
> 上镜尾帧 = 本镜首帧、每镜独立过 出稿前逻辑审核。

### 3 追问（生成方向的思考引擎）

拿到第一镜（成片或 shotlist 尾拍）后，先问三个问题：

1. **第一镜留下了什么未完成？**（悬念 / 因果缺口 / 尚未兑现的承诺）
   → 最有**意义**的续镜 = 回答第一镜的未完成。
2. **观众此刻最想知道什么？**（信息差 / 视角遮蔽 / 认知缺口）
   → 最**符合逻辑**的续镜 = 满足刚被吊起的欲望。
3. **什么能顺着因果给出预期反转？**（前提颠覆 / 规模跃迁 / 主题深化）
   → 最**震撼**的续镜 = 由第一镜因果支撑的意外，而非无中生有。

### 3 方向模板（与 FirstShot 弧光同构）

| 方向 | 推进力 | 一句话特征 | 典型触发 |
|------|--------|------------|----------|
| **A 顺势** | 回答悬念 | "然后呢"——延续因果链，兑现第一镜埋的钩子 | 第一镜结束在"欲知后事" |
| **B 换维** | 信息差 | "换个视角看"——同一世界换尺度/主体/时间，揭示第一镜看不到的 | 第一镜是单人/单景/单主体 |
| **C 反预期** | 预期反转 | "它不是你以为的那样"——顺着因果颠覆前提，主题深化 | 第一镜建立了某个表面认知 |

### 每个方向必含 4 要素（同 FirstShot UG）

1. **推进主轴**（一句话：本镜回答什么 / 揭示什么 / 颠覆什么）
2. **开场↔终场视觉对照**（本镜内部的 show change）
3. **生成策略**（上镜尾帧 = 本镜首帧 + 模型 + 连贯性 + 预计成本）
4. **时长 / 格式**（默认 Single15；用户要求"一次过生成"时走 A0 SinglePass；跨大空间/多事件才拆 A+/C）

> 方向选择后 → 场景变换定为合法 Delta → 走 NextShot 全规则链（SKILL.md「NextShot」段 9 步）。
