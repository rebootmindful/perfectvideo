# 材质宪法（Material Constitution）· 含全文金样

## 定义

全片（或本链）所有人/物/建筑/环境 **共用的材质语言与禁止边界**。  
这是跨主体一致性的**高一阶锁**，高于「只锁脸」。

## 为何存在

- 竞品多做 character bible；奇观密度一高就材质分裂  
- 一次宪法把 N 人身份成本压成「1 套物理语言 + 锚点」  
- 与 `timeline.morph_chain` 配合：变的是状态，不变的是宪法体系  

## 预设（v0.1 最小集 · 每套附可焊接全文）

> **用法：** 把下方「金样全文」整段拷入 `lock.material`，每镜原样焊接；`forbidden` 并入 negative 包。

### 1. fluid-sculpture（流体雕塑）

**金样全文（可直贴 lock.material）：**

```text
【材质宪法 · 统一三维东方流体雕塑系统】
- 全部人物/动物/建筑/山石/烟云共用同一种流体语言，不存在任何材质边界。
- 人物肌肤统一温润瓷器质感，半哑光，反光克制。
- 衣物统一半透明流体丝绸，随气流延展，可融入烟云。
- 长发均逐渐演化成液态水墨，墨色流动方向统一。
- 山石采用凝固墨汁雕塑材质；镜面墨池采用湿润树脂镜面。
- 巨大流体圆环以液态水墨+白玉+液态鎏金共同塑造。
- 全场光影一致动机，无跳变、无随机切换、无材质闪烁。
```

**forbidden：** 材质边界、塑料高光、二维水墨突变、赛博机械乱入、随机喷溅

### 2. ink-breath（水墨呼吸）

**金样全文：**

```text
【材质宪法 · 统一水墨呼吸系统】
- 纸本肌理为世界底色，墨为万物之体，水渍与飞白为统一笔触语言。
- 人物肤色近似宣纸晕染，衣料为墨色流纱，边缘留飞白。
- 山石/建筑为焦墨皴擦质感，近实远虚。
- 烟云为淡墨渗化，可承担环境主运动。
- 实写与留白同权；全片保持纸面呼吸感，无厚重油润感。
```

**forbidden：** 厚重 PBR 塑料、霓虹赛博默认、浓彩油画突兀

### 3. bronze-reliquary（青铜圣物）

**金样全文：**

```text
【材质宪法 · 统一青铜圣物系统】
- 主材质为铸铜与铜绿风化层，金属高光克制。
- 织物为粗织麻/棉，与铜表面形成哑光对照。
- 石材与铜皮同属「岁月沉积」语言，尘与体积光同源。
- 人物肌肤偏暖陶土感，不抛光不塑料。
- 全片保持旧物质感，光影低反差，无玻璃未来感。
```

**forbidden：** 玻璃未来感、动漫塑料、抛光镜面金属、色彩荧光

### 4. neon-noir（霓虹夜色）

**金样全文：**

```text
【材质宪法 · 统一霓虹夜色系统】
- 湿柏油路面、镀铬克制反射、氖管色温分区为统一语言。
- 人物肌肤与织物统一在「潮夜胶片」质感，微湿、低饱和。
- 玻璃与金属只以冷色高光点出现，不喧宾夺主。
- 全片夜雨湿润感一致，光为分区色温（青/品红/暖橙），不混光。
```

**forbidden：** 童话马卡龙色、水墨突变、日光爆亮、全彩混光

### 5. natural-doc（自然纪实）

**金样全文：**

```text
【材质宪法 · 统一自然纪实系统】
- 真实棉麻/皮肤毛孔/环境尘粒，低奇观，不美颜不塑料。
- 同一时空同一成像：一台机身一种胶片感贯穿全片。
- 光线以自然/实用光源为准，不添加魔法光效。
- 全片颗粒一致，色彩统一，无素材跳变。
```

**forbidden：** 美颜磨皮、塑料肤、空背景影楼感、魔法光效、色调突变

## 字段建议

```text
material.id
material.constitution   # 全文，进 lock（金样整段拷入）
material.shared_rules[] # 法则条
material.forbidden[]    # 材质禁区 → 并入 negative
material.morph_allowed  # bool / 条件
```

## 冻结与变更

- S2 确认后写入 lock，全文焊接  
- 更换预设 = **断链**，不是 delta  
- 自定义宪法：用户一句话 → 导演扩成同构金样（统一语言 + forbidden）
