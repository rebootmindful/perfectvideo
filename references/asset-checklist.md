# 素材准备清单（Asset Checklist）

> 用途：每次编译前，告诉用户「生成前准备什么素材」——避免生成到一半才发现缺参考图。  
> 借鉴：seedance-cinematic-video 的素材准备清单。  
> 铁律：**清单在锁定卡确认前给出**（U✅ 前），用户可提前备料或选择纯文生降级。

---

## 1. 清单格式（每次交付必含）

```text
【素材准备清单】（模式 A/B/C · 有无参考图）
□ @人物 n 张：{描述}（jpg/png，清晰，无 logo，正面或全身）
□ @人物2 n 张（如多主体）：{描述}
□ @道具 n 张（可选）：{描述}
□ @环境 n 张：{描述}（画幅对齐 {aspect_ratio}）
□ 首帧 1 张（NextShot 链必填）：上一镜尾帧
□ 尾帧 1 张（可选）：本镜落幅构图
──
无素材？→ 降级纯文生视频（@槽位用文字描述替代），连戏靠字面量焊接
```

---

## 2. 规则

| 情况 | 行为 |
|------|------|
| 用户有参考图 | 槽位绑定 → 双锚硬控制（连戏 99%） |
| 用户无参考图 | 纯文生 + 文字锁（连戏 90%）→ 标注「连戏降级」 |
| NextShot 链 | 首帧 = 上镜尾帧，**自动继承，无需用户准备** |
| 多主体 | 每人一个槽位（@人物/@人物2…），清单分列 |
| 素材超限 | H3 参考图 ≤9 → 合并或降级 |

---

## 3. 与输出契约的关系

- 清单是 `output-contract.md` 交付块的一部分（第 0 块，最先给）
- 清单内容来自 schema `frame_ref` 槽位声明
- QC 闸门：清单存在 + 槽位与 prompt 引用一致

---

## 4. 快速默认（导演静默推断）

用户不说要参考图 → 默认「纯文生」，清单写 `无需素材（纯文生）`；  
用户提到「有张图/用首帧/保持那个人」→ 导演推断槽位，清单列出来等用户补图路径。
