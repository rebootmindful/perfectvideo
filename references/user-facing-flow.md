# 用户可见交互契约（对齐 PerfectPhoto 问数）

**铁律：对用户只暴露 U0–U6 + 冻结确认（约 7～8 次表态）。禁止把 S0–S12 逐步问成马拉松。**

内部管线仍是 S0–S12；下表是 **U ↔ S 映射**。未出现在「用户开口」列的字段 = **导演静默代填**。

## 问数预算

| 路径 | 用户大约回几句 | 说明 |
|------|----------------|------|
| 标准纯视觉 | **7～8** | 开场 1 + U1–U6 + 冻结 1（U0 开场可与意图合并） |
| 快速模式 | **2～3** | 一次说满 → 编译展示 → 冻结确认 → 出稿 |
| path.vo | **+0～1** | 仅用户提起旁白/要解说时加半步 |
| NextShot 每镜 | **1～3** | 1 句 delta + 最多 2 轮补缺（同 Photo） |

**禁止：** 单条首片前超过 **10** 次「必须回答」的提问（用户主动展开除外）。

## 开场话术（必须，同构 Photo 预告问数）

```
我来帮你做一份艺术短片的「拍摄总谱」——
不是抽卡许愿，也不是爆款钩子文案，而是可连戏的视觉契约：概述、分镜、锁定域、可粘贴提示词。

对你大概 **7～8 个小问题**（纯视觉）。每问给选项，挑一个或说你的想法就行。
有艺术旁白再加半步；我不会写「关注点赞看到最后」。

问题大致是：
0️⃣ 片子感觉 — 脑子里这段影像是什么
1️⃣ 发布规格 — 平台 / 画幅 / 多长（一问打包）
2️⃣ 材质世界 — 选一套全片统一的材质宪法
3️⃣ 人物与物 — 谁、穿什么、帽/手里什么
4️⃣ 舞台空间 — 站哪、远近、留白
5️⃣ 时间轴 — 这几十秒里主要发生什么
6️⃣ 镜头怎么动 — 含可选名家味道
✅ 锁定确认 — 一眼看锁定卡，点头就编译

准备好了，先告诉我：你脑子里的短片是什么样的？
一个场景、一种气质、一句诗、一个模糊画面都行。
比如：「雨巷一把伞」「流体雕塑神女 15 秒」「球鞋特写一镜推到鞋面」……
```

## U 步细则

### U0 · 片子感觉（1 次必答）

- 用户自由说。  
- **意图编译（不逐项问卷）**：从话里推断——情绪/视觉核心/年代或气质/道具苗头 + 视频维草稿。  
- 展示短编译卡，**一句**「哪里跑偏说一声，没问题进入下一步」——不要 7 维逐条确认。  

静默填：预算主花销初判、mode 初判。

### U1 · 发布规格（1 问打包）

一次问清（给选项）：

- 平台：抖音 / 视频号 / B站 / YouTube / 不限  
- 画幅：9:16 / 16:9 / 1:1 / 21:9  
- 成片大概多久：≤15s / 约 30–60s / 更长  
- path：默认纯视觉；选项里可带「要艺术旁白」  

静默：`model_clip_budget_s` 默认 15；target>15 → 预告模式 C。  
映射：S0 overview。

### U2 · 材质世界（1 问）

选项 = 材质预设卡（fluid-sculpture / ink-breath / bronze / neon-noir / natural-doc / 自定义一句话）。  
用户一选 → 填 `material` + 推断 `world` 要点。  
映射：S1–S2。  
**勿**拆成「先问世界法则再问材质」两轮。

### U3 · 人物与物（1～2 问，优先压成 1）

尽量一问打包选项/填空：

- 几人、气质  
- 服装主色与款式  
- **帽饰有/无**（独立）  
- 手里/身上关键道具归属  

信息够 1 轮结束；明显缺帽/道具锚再追 **1** 轮（仍 ≤2 问总占用）。  
映射：S3。

### U4 · 舞台空间（1 问）

选项：景别层次 / 是否群像分散 / 留白强弱 / 主场景一句话。  
映射：S4。  
米制 blocking：导演可代写，不单独盘问。

### U5 · 时间轴事件（1 问）

「这 `model_clip` 秒里，最想被看见的 1～3 个瞬间？」给节拍选项（睁眼 / 抬手 / 走过门灯 / 产品转面…）。  
导演展开为 beats + shotlist 时间码。  
映射：S7（+ 需要时 S8 morph 静默）。  
**勿**按 0–3 / 3–6 / 6–9 逐段逼问。

### U6 · 镜头怎么动（1 问 · 三档意图选择）

先给「运镜意图」三档（这是惊艳度的主旋钮），再按档位给选项：

| 档位 | 一句话 | 代表选项 |
|------|--------|----------|
| **A 克制** | 庄严安静，镜头几乎不动 | 固定 / 极缓推 / 微跟 |
| **B 电影感** | 有呼吸的叙事运镜 | 缓推+轻环绕 / 跟随+落幅 |
| **C 签名惊艳** | 一条签名运镜做足 | 螺旋升巡 / 推拉变焦 / 前景穿梭 / 环景升降 / 悬浮漂移 / 一镜穿越 / 抽帧 / 环绕凝视 |

- 选 **A/B**：按基础运镜编译（`references/camera-moves.md` §1）
- 选 **C**：展开签名清单（§2），或直接说「导演帮我选」→ 按题材自动挑一个 C 档签名，锁定卡上展示确认
- **可选叠加**：名家味道（不选 = 标准矩阵）；选 C+大师 → **大师签名优先**，不叠两条
- **预算联动（导演静默）**：`identity` 预算时 C 档自动降 B；`motion` 预算才放行强签名

映射：S9（签名运镜写死度数/高度/次数）。  
光、diegetic 声锚：S10 **静默写满**，不单问「有几个环境声」。

### U✅ · 锁定确认（1 次）

展示 **结构化锁定卡**（人/衣帽/道具归属/环境 anchors/材质/overview 要点）。  
用户确认或改一句 → `bible_version` 冻结 → **直接 S11 编译交付**，中间不再穿插问卷。

### U+ · 旁白半步（仅 path.vo 或用户提起）

- 「用你的原文 / 我写诗性旁白 / 不要旁白」三选一  
- 禁止推销钩子 CTA  
- 映射：S10 vo/subtitles

## 导演静默代填（禁止单独占一轮）

| 项 | 默认策略 |
|----|----------|
| budget.primary | 按题材推断，QC 里写一句取舍 |
| mode A/B/C | target≤model 且一事 → A；否则 C 或 B |
| morph | 题材需要再写；不问「要不要材质转化」 |
| diegetic_audio | ≥2 锚，自动 |
| lighting 相位 | 从材质与场景推 |
| tech.spec | 降权或省略 |
| negatives | 按题材包自动 |
| anti-slop / CTA 扫描 | 自动 |
| title | 可从主题生成艺术向标题，确认卡上可改 |

## 快速模式

用户第一条已含：题材 + 人服 + 场景 + 时长画幅 + 动作 →  

1. 展示编译 + 锁定卡草案（1 条消息）  
2. 用户「没问题/改 XX」  
3. 直接出 overview + shotlist + primary + QC  

跳过 U1–U6 逐步点选。

---

## NextShot（U 之后）

不重走 U0–U6。  

1. 用户说下一镜 delta（1 句）  
2. 缺字段最多 **2** 轮追问  
3. 焊接 lock → 双产物 → diff

## Agent 自检（每轮提问前）

- [ ] 本轮是否在 U0–U6 / 冻结 / VO 半步 / NextShot 内？  
- [ ] 是否误把 S5/S8/声光/QC 问出口了？→ 收回自填  
- [ ] 首片累计强制提问是否已 ≥10？→ 停止追问，用合理默认出锁定卡
