# 旁白与画面同步细则（path.vo）

## 原则

1. **VO 不抢画**：旁白说 A 时，画面焦点 = A；禁止画面演 B、嘴里念 C。  
2. **VO 密度 ≤ 画面信息密度**：宁可减句量，不塞满每帧。  
3. **呼吸留白**：关键视觉瞬间（材质 morph、落幅）留 1–2s 无旁白。  
4. **不生成 CTA**：关注/点赞/看到最后一律禁止；用户原文挂载不改写。

## 时间对齐规则

```text
vo_line.t_in / t_out 必须落在 shotlist 某一行或跨行区间
字幕 cue 与 vo 对齐，可稍晚 0.1–0.3s（跟随口播）
单行字幕 ≤ 16–18 字（竖屏更短），长句拆两行
情绪标签：静 / 紧迫 / 抒情 / 纪实 —— 标在 vo 行尾
```

## 冲突检查

| 情况 | 处理 |
|------|------|
| VO 说「雨落伞面」但画面是近脸 | 移 VO 到对应画面段或改画面 beat |
| VO 密度超过 3 句/3s | 压缩为 1–2 句或拆镜 |
| VO 出现 CTA 词 | 拦截删除（红线） |
| 用户原文与画面不符 | 提示用户或按画面重排时间，**不改写文案营销化** |

## 与 diegetic_audio 分工

- diegetic = 画面内声（水声、琴弦、脚步）——**不占 VO 字数**  
- VO = 解说轨；两者可叠加，但 VO 处弱化 BGM 提示
