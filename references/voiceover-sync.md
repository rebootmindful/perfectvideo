# 旁白与画面同步细则（path.vo + 口播量化）

## 原则

1. **VO 不抢画**：旁白说 A 时，画面焦点 = A；禁止画面演 B、嘴里念 C。  
2. **VO 密度 ≤ 画面信息密度**：宁可减句量，不塞满每帧。  
3. **呼吸留白**：关键视觉瞬间（材质 morph、落幅）留 1–2s 无旁白。  
4. **不生成 CTA**：关注/点赞/看到最后一律禁止；用户原文挂载不改写。

## 口播量化工具（同行评审新增 · 2026-08-07）

> 口播视频（人物说话）是独立物种：字数/秒、停顿、重音都要量化，否则音画脱节。

| 指标 | 行业经验法则 | 说明 |
|------|--------------|------|
| **语速** | 中文口播 **240–280 字/分钟**（≈4–4.7 字/秒） | 知识口播取 260±；情绪抒情取 220；急促取 300 |
| **单句长度** | ≤ 22 字（口语），长句拆短句 | 一呼一吸一句 |
| **停顿时长** | 句号 0.3–0.5s；段落 0.8–1.2s | 情绪重音前留 0.3s |
| **重音密度** | 每 10–14 字 1 个重音 | 用 **加粗** 标注 |
| **时长换算** | 3 分钟 ≈ 780 字；15s ≈ 65–70 字 | 反推字数：`秒数 × 4.3` |

### 口播稿格式（进 prompts.vo）

```text
【旁白 · 口播量化】
0:00-0:03（65 字总预算的起句）：
  「**你说** 中医只讲玄学？先听这个。」
  （重音：你说 / 情绪：钩子句，平稳）
0:03-0:08（中段，260 字/分）：
  「三年前我拍过一条**二十八秒**的片子，讲**气血**怎么在血管里流动。」
  （重音：二十八秒、气血 / 情绪：叙事，渐入）
0:08-0:15（落幅，放慢）：
  「后来我发现——**看懂它**，比记住名字重要。」
  （重音：看懂它 / 情绪：抒情，放缓）
```

### 口播校验规则

- **字数反推**：每段旁白字数 ≈ 段长(秒) × 4.3（±10%），超了压缩
- **单句 ≤22 字**，超则拆
- **每段 ≤3 句**（15s 三段的节奏）
- 重音用加粗标（TTS 朗读时加重）
- 与 diegetic_audio 不重叠（口播时不压环境声）

## 时间对齐规则

```text
vo_line.t_in / t_out 必须落在 shotlist 某一行或跨行区间
字幕 cue 与 vo 对齐，可稍晚 0.1–0.3s（跟随口播）
单行字幕 ≤ 16–18 字（竖屏更短），长句拆两行
情绪标签：静 / 紧迫 / 抒情 / 纪实 —— 标在 vo 行尾
```

## 冲突检查

| 情况 | 处理 |
|------|------|
| VO 说「雨落伞面」但画面是近脸 | 移 VO 到对应画面段或改画面 beat |
| VO 密度超过 3 句/3s | 压缩为 1–2 句或拆镜 |
| VO 出现 CTA 词 | 拦截删除（红线） |
| 用户原文与画面不符 | 提示用户或按画面重排时间，**不改写文案营销化** |

## 与 diegetic_audio 分工

- diegetic = 画面内声（水声、琴弦、脚步）——**不占 VO 字数**  
- VO = 解说轨；两者可叠加，但 VO 处弱化 BGM 提示
