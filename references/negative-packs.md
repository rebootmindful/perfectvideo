# Negative 题材包 & Anti-slop 禁词表

> 用途：`prompts.primary` 与 by_tool 输出的 `negatives.pack` 依据；QC 闸门引用本表。  
> 规则：**题材包 = 基础包 + 题材专属**；anti-slop 词全局适用；不机械堆砌，按片子裁。

---

## 0. 基础负面包（所有题材默认）

```text
二维动画、平面插画、动漫脸、塑料质感、蜡像皮肤、过度磨皮、人物漂移、
五官变化、服装变化、穿模、文字乱码、水印logo、镜头跳切、曝光闪烁、
随机抖动、背景突变、过曝、死黑、色彩溢出、字幕乱入、构图截头
```

## 1. 奇观 / 神话 / 幻想包（fluid-sculpture 等）

```text
三维流体雕塑 → 追加：材质边界、随机喷溅、快速旋转、能量爆闪、
科幻机械乱入、赛博霓虹（除非题材即 neon）、塑料高光、二维水墨突变、
人物重叠穿模、武器穿模
```

## 2. 写实 / 纪实 / 剧情包

```text
磨皮美颜、网红滤镜、过度锐化、空背景影楼感、夸张表情、摆拍感、
塑料皮肤、假笑、背景人消失（连戏约束下）、时间跳跃、光照动机切换
```

## 3. 产品 / 商业包

```text
产品变形、logo 模糊、反光乱跳、指纹脏污、比例失衡、背景抢产品、
手持抖动（除非题材）、色差、材质跳变、文字残影
```

## 4. 对白 / 人物近景包

```text
口型不同步、眨眼僵硬、眼球乱动、表情抽搐、牙齿穿模、头发飘忽、
视线漂移、五官融合、变老变年轻
```

---

## 5. Anti-slop 禁词（QC 扫描 · 全局）

出现即视为空转修辞，建议删除或换成物理描述：

```text
cinematic, epic, breathtaking, stunning, masterpiece, award-winning,
majestic, divine, ethereal（若未配物理描写）, magical glow（无来源）,
unreal beauty, hyper-realistic（无物理锚）, perfect, 氛围感, 高级感,
大片感, 史诗感, 震撼, 美到窒息, 一眼万年（无叙事）
```

**反例示范：**

| ❌ 空转 | ✅ 物理化 |
|---------|----------|
| cinematic lighting | 侧逆光 45°，轮廓金边 1px，暗部灰黑不死黑 |
| epic atmosphere | 雾白烟基灰底，墨黑+鎏金两层层次，红带唯一暖点 |
| divine presence | 金月正逆光包裹，衣缘通透边，光柱粒子闪烁 |

---

## 6. 平台敏感词（艺术向仍要自查）

- 绝对化广告词（最好/第一/唯一/全网最低）→ 商业场景禁用  
- 医疗/金融/功效承诺类 → 明确不生成  
- 人物默认成年；儿童题材须合规内容  
- 名人肖像/商标/音乐版权 → footer 复核项

## 7. QC 使用

`boundaries-and-qc.md` 闸门：「负面包已附」= 至少基础包 + 题材包任一；「anti-slop」= 扫描 §5 词表，命中 ≥2 处需回改。
