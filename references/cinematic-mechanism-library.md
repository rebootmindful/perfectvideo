# 电影机制库 · Director's Imagination Protocol

> **用途：** 把"用户一句话模糊意图"长出"令人惊喜的顶级电影细节"的**方法 + 弹药库**。
> **移植自：** `movie-development-skill` 的核心方法论（机制库 + 重组纪律），适配 AI 视频提示词场景。
> **何时读：** 用户要"详细 / 电影感 / 顶级细节"，或题材属 world-heavy / action-immersive / cinematic-grade，触发**深度档**时。

---

## 0. 先破一个迷思：深度 ≠ 字数

案例对比证明：第一条 2000 字（东方神话流体雕塑）和第二条 600 字（飞龙穿行 FPV）**都极深**，但结构完全不同。深度来自**分解架构 + 机制复用**，不是篇幅。

- **堆字数但无机制** → 模型读疲、漂移、丢重点（尤其 H3/Seedance）。
- **有机制但极简** → 紧凑 lock，模型精准执行（PV 默认档）。
- **有机制且分层展开** → Director's Bible，给人/高端模型加戏（本文件服务的深度档）。

---

## 1. Director's Imagination 五步协议

从模糊意图到惊喜细节的固定链路（LLM 想象被**机制库 + 纪律**引导，而非自由发挥）：

| 步 | 动作 | 产出 |
|----|------|------|
| ① 意图编译 | 把用户感觉蒸馏成**一句世界概念隐喻** + 情绪/视觉/气质三维 | "墨与水化为万物之体" |
| ② 选架构 | Tableau（慢·多主体·材质连续）vs Kinetic（动作·速度·沉浸） | 架构选定 |
| ③ 抽机制 | 按"情绪/题材/镜头意图"从下方机制库拉 **3–6 张卡** | 机制组合 |
| ④ 重组落地 | 把机制卡翻译成**可见事件**（指定身体部位/惯性/光向/材质演化） | 逐拍/相位流文本 |
| ⑤ 锁深度档 | 紧凑 lock 给模型；Director's Bible 给人/高端，**分层互不污染** | 双产物 |

---

## 2. 电影机制卡库（可迁移，不绑定具体影片）

每张卡：**做什么 / 何时用 / 提示词语感**。LLM 按题材抽取重组，禁止原样抄某片。

### 2.1 焦距与光学（焦距即情绪）
- **超广角 10–16mm（FPV/鱼眼）**：空间拉伸、边缘放射模糊、速度失重 → 冲刺/穿越/第一人称沉浸。语感："10mm 超广，画面边缘云层带状高速掠过，放射状动态模糊"。
- **广角 24–35mm**：环境叙事、大景深、代入 → 建立世界/群像。语感："24mm 广角，前景丝绸自然引导纵深"。
- **中焦 40–70mm**：人脸/对话、压缩弱 → 角色情绪特写。语感："50mm 中焦，面部微表情主导"。
- **长焦 85–200mm**：空间压缩、背景虚化、孤立/偷窥 → 分离主体、压缩层次。语感："135mm 压缩远景山峦贴合主体"。
- **变形宽银幕 Anamorphic**：横向光斑、椭圆散景、史诗 → 西部/科幻/宏大。语感："anamorphic 横向蓝斑，史诗画卷"。

### 2.2 光向与光影（光向即心理）
- **侧逆光（身后平射）**：轮廓分离、神秘、神圣、剪影 → 史诗/英雄/神话。语感："侧逆光自主体身后平射，白纱边缘勾明亮金边"。
- **侧顺光（前侧）**：立体塑形、皮肤质感、亲和 → 人物特写/写实。语感："侧顺光自前侧偏右，衣袍纹理清晰勾勒"。
- **顶光**：审判/压抑/戏剧 → 紧张/审讯。语感："顶光直落，眼窝阴影加重"。
- **底光**：恐怖/诡异/非自然 → 惊悚。语感："微底光托起下颌，诡谲"。
- **体积光/上帝光**：神圣/希望/剧场 → 史诗收尾。语感："体积光自云隙倾泻，尘埃金粒悬浮"。

### 2.3 运动语法（运动即情绪）
- **缓推 dolly in**：进入内心/压迫/亲密。语感："稳定器缓推至中景，呼吸逼近"。
- **缓拉 dolly out**：孤独/疏离/全景收束。语感："镜头缓拉，人物缩入天地"。
- **环绕 orbit**：权力审视/眩晕/仪式。语感："环绕轨迹缓慢推进，半圆展现全貌"。
- **螺旋升 optical rise**：史诗/超越/觉醒。语感："侧面中景螺旋上升至高位俯瞰，升 1.5m 旋 180°"。
- **手持/肩扛**：真实/慌乱/临场。语感："轻微手持呼吸感，不维稳"。
- **FPV 尾随**：速度/失重/沉浸。语感："摄影机位于主体正后略高，物理连动同步"。
- **快照 Whip pan**：时间跳跃/冲击。语感："whip pan 甩接下一时空"。
- **子弹时间**：决策/高潮定格。语感："瞬间降速，发丝悬停，尘埃定格"。

### 2.4 材质统一语言（干掉跨帧不一致）
- **统一流体语言**：所有元素共用一种材质演化（长发化墨、衣袖连云、山石凝墨）→ 梦幻/跨帧一致。语感："全片共用同一种流体语言，不存在材质边界"。
- **温润瓷器肌肤**：高级感、非塑料、非蜡像。语感："肌肤统一温润瓷器质感"。
- **古旧金箔裂纹**：神圣/时间感。语感："古旧金箔裂纹，鎏金纹理若隐若现"。
- **凝固雕塑材质**：静态永恒。语感："山石全部凝固墨汁雕塑材质"。
- **半透明流体丝绸**：轻盈/神性。语感："衣物统一半透明流体丝绸，衣袖连接天地烟云"。

### 2.5 构图纵深（空间即呼吸）
- **前景引导**：丝绸/墨流/枝叶做前景框 → 纵深 + 自然转场。语感："前景流体自然形成空间视觉引导"。
- **留白**：东方意境、呼吸。语感："保留约 45% 东方留白"。
- **层次 L1/L2/L3**：主体/中景/远景分层 → 纵深。语感："白发剑尊第二层，流体圆环第三层"。
- **天地呼应/左右平衡**：语感："上下天地呼应，左右视觉平衡"。

### 2.6 色温心理
- **暖金**：神圣/怀旧/希望。语感："柔和暖金光辉自然照耀天地"。
- **青灰冷**：疏离/湿冷/现实。语感："雾白烟基灰底，青灰主调"。
- **唯一暖点**：焦点引导（青灰中一门灯/红衣）。语感："红色飘带为唯一暖色跳点"。
- **高饱和冲突**：张力/超现实。

### 2.7 画面内声锚（真实感来源）
- **diegetic 微声**：雨打伞/檐水/衣料摩擦/鳞片震颤 → 真实。语感："鳞片在高速气流中细微抖动，带出白色流体涡流"。
- **共鸣扩散**：琴音/钟声 → 世界呼吸。语感："琴音持续扩散，与法坛烟雾连接"。

## 3. 重组纪律（铁则 · 抄自 movie-dev 的"可见事件"原则）

1. **可见事件原则**：禁止抽象词（"紧张""宏大""电影感"）。必须写**哪个部位动 + 惯性后果**。✅ "仅胸腔轻微呼吸起伏，随后缓缓睁眼，眼神由下方向远方望"。❌ "人物表现得很神圣"。
2. **统一语言原则**：每题材选**一种**材质语法，全片强制出现"共用同一种语言/不存在材质边界"硬条款。
3. **焦距即情绪原则**：永远写明**镜头焦距 + 光向**，不写"电影感"三字。
4. **架构匹配原则**：慢·多主体→Tableau（time-beat）；动作·速度→Kinetic（phase-flow）。
5. **收尾帧必锁**：无论哪种架构，必写最终构图（"镜头收束在…形成完整史诗画面"）。
6. **机制不抄片**：机制卡只取"功能/语义"，重组为原创描述，不复用某片具体桥段。

---

## 4. 与紧凑 lock 的分层关系

```
[ 紧凑 lock ]  ──► 模型吃（防漂移、省 token、保执行度）
[ Director's Bible（本档产出）] ──► 人审 / 高端模型（frontier）加戏
```
深度档**不修改**紧凑 lock 的内容，只在冻结后**额外**产出 Bible（world-bible-depth 或 kinetic-fpv-depth 模板）。两者可并存：人拿 Bible 调，模型拿 lock 跑。

---

## 5. 触发与降级

- **升档（开 Bible）**：用户显式要详细/电影感/顶级细节；或题材 world-heavy（神话/流体/抽象）/ action-immersive（FPV/追逐/打斗）/ cinematic-grade（指定高端模型）。
- **降级（只给 lock）**：模型为 H3/Seedance 且用户未要求深度；或 target 短、诉求简单。绝不为了"显得专业"硬塞 Bible 给便宜模型。

## 6. 意图层 + 动机层（第二轮精髓 · 让细节"配得上"）

机制库负责"长出细节"，但这三层让细节**有准星、有因、免抄**——移植自 `movie-development-skill` 的场景公式 / 人物原型 / 机制模仿纪律。完整诊断见 `references/diagnose-repair.md`。

### 6.1 镜头机制检查表（每镜必答 · 这一镜为何存在）

| 问 | 答什么 | 反例（白拍） |
|----|--------|--------------|
| **镜头主权** | 谁占 frame？主体还是环境？ | 含糊"两人打斗" |
| **信息差** | 主体知什么、观众知什么不同？视线差造张力 | 双方都知道，无悬念 |
| **升级** | 比上镜能量/距离/风险推进了？ | 平推无进展（半步缓行） |
| **转折落点** | 是否埋"下镜要兑现"的钩子？ | 孤立事件无衔接 |
| **状态改变** | 人物/局势/环境是否不可逆地变？下镜不可复位 | 打完又回到原点 |

> 红线呼应：状态改变不可复位 = PV "连戏不可跳变"的微观版。

### 6.2 主体驱动力（微动作有因 · 人物原型六问精简）

微动作必须由 **欲望 / 恐惧 / 压力** 驱动，不是装饰。先标驱动力标签，再落动作：

- **惧者**：缩、守、侧身护要害、视线游离 → 防御性微动。
- **欲者**：探、倾身、指尖前伸、视线锁死目标 → 进攻性微动。
- **压者**：肩沉、呼吸压、步伐稳如山 → 压迫性微动。

语感："白衣侠惊觉破绽，瞳孔微缩，重心后撤半步护喉"——因（惧破绽）果（后撤）清晰。

### 6.3 机制模仿不抄剧情（anti-plagiarism）

movie-dev 铁律："模仿《X》的【Y】机制但不复制剧情"。PV 同理：

- ✅ "模仿《卧虎藏龙》竹林的【运动机制：轻功踏竹借力腾空、衣袂贲张】但不抄其镜头"
- ❌ "像《卧虎藏龙》竹林那场那样打"

风格可迁移、免抄，既专业又避争议。
