# 真声轨（Native Audio · C 档惊艳）

> 用途：把 diegetic_audio 从「写在 prompt 里的文字」变成「模型生成的真实声音」——沉浸感 ×2，几乎零成本。  
> 适用：MiniMax-H3 / Kling 3.0（native audio 模型）；旧模型无原生声轨时退回文字锚。  
> 来源：Kling 3.0 / H3 官方能力（native audio）+ 本 skill 声画三轨契约。

---

## 1. 什么是真声轨

| | 文字锚（旧） | 真声轨（新） |
|--|--------------|--------------|
| 形态 | prompt 里写「雨打伞面、檐铃」 | 模型直接生成真实声音 |
| 沉浸 | 画面里的想象声 | 耳朵能听到的现场声 |
| 成本 | 0 | 0（同一 prompt 语法） |
| 适用 | 所有模型 | H3 / Kling 3.0 |

**铁律：** 有 native audio 的模型（H3 / Kling 3.0）**必须**用真声轨；老模型自动降级为文字锚（不阻塞）。

---

## 2. 真声轨写法（进 prompts.primary）

### 2.1 结构：三幕声场（可进 prompt 的物理描述）

```text
【画面内声 · 真声轨】
环境基底：{持续的环境声，如} 云海低频涌动、风过松林
关键事件：{随画面变化的单次声，如} 白鹭掠空一声振翅、檐铃一声金属清响
情绪落点：{收尾的情绪声，如} 风声渐弱、远处钟声余韵
```

### 2.2 三轨原则（与 diegetic 一致，但升级为「真声」）

| 层 | 内容 | 例 |
|----|------|-----|
| 基底 | 持续环境声（可循环） | 云海涌动 / 风过松针 / 雨声 |
| 事件 | 单次关键声（与节拍对齐） | 白鹭振翅 / 檐铃 / 脚步 / 布料翻飞 |
| 情绪 | 收尾情绪声 | 渐弱风声 / 钟声 / 静默一拍 |

### 2.3 禁忌

- **真声轨 ≠ 音效堆砌**：一场戏 2–4 个声即可，多则吵
- **真声轨 ≠ 配乐**：不写「背景音乐 BGM」——那是宿主剪辑的活
- 不要写「风声很大」这种模糊词，写「风持续中速，掠过松针沙沙」

---

## 3. 真声轨 × 节拍对齐（与 shotlist 同步）

```text
0-3s   基底：风过松针沙沙        事件：白鹭振翅一声（远）
3-6s   基底：云海低频涌动        事件：风渐强
6-9s   基底：同上               事件：衣袂翻飞一声
9-12s  基底：云海涌动            事件：远处檐铃一声（金属清响）
12-15s 基底：风渐弱             事件：静默一拍，余韵
```

---

## 4. by_tool 映射

| 模型 | 真声轨支持 | 写法 |
|------|-----------|------|
| MiniMax-H3 | ✅ native audio | 直接写「画面内声」段（模型自带生成） |
| Kling 3.0 | ✅ native audio | 同 H3 |
| Kling 2.x / Seedance / 老模 | ❌ | 退回文字锚（仍在 prompt 里写，但标注「需宿主配音」） |

---

## 5. QC 闸门

- [ ] 真声轨存在（基底 + 事件 + 情绪，≥2 层）  
- [ ] 事件声与节拍对齐（每拍 1 个关键声）  
- [ ] 无「BGM/配乐」字样（那是宿主活）  
- [ ] 声数克制（一场 2–4 个，不堆砌）  
- [ ] 老模型已标注「需宿主配音」降级提示
