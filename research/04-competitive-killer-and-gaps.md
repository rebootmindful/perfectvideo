# PerfectVideo：杀手锏、竞品地图、仍缺什么

**日期：** 2026-08-06  
**视角：** 视频导演 / 制片，不是词库产品经理  
**前提：** PerfectVideo = 导演对话层 skill（不做 auvideo 编排、不做复刻管线、不做提示词大全）

---

## 0. 一句话 thesis

> 同类竞争者大多在卖「更好看的运镜词」或「更长的模板」。  
> PerfectVideo 若做成，卖的是 **世界宪法 + 跨镜只读锁 + 15 秒预算时间码 + 名家矩阵**——  
> 这是从「提示词工具」跃到「可连戏的短片编剧/摄影指导」。

**真杀手锏只有一个叠起来的系统，不是五个并列功能。**

---

## 1. 竞品地图（同类在卖什么）

| 类型 | 代表 | 他们强在哪 | 他们弱在哪 | PerfectVideo 是否硬碰 |
|------|------|------------|------------|------------------------|
| **词库 / 模板 pack** | 各类 cinematic prompts 合集 | 上手快、灵感多 | 无状态、无锁、一镜一抽卡 | ❌ 绝不做 |
| **平台槽位编译器** | Seedance @槽位类 skill | 贴模型接口、六层结构 | 缺世界宪法、缺交互导演问答 | 可对接输出格式，不当核心 |
| **现实主义剧片管线** | ai-cinematic-pipeline | Visual Bible、尾帧链、immutable | 弱奇观/材质/世界呼吸 | 偷规则，不做全管线 |
| **诊断型提示词工程师** | cinematic-video-prompt-engineer | 先诊断、时间轴、反油腻 | 少跨镜 Memory Pack；群像预算紧 | 吞进 S0 诊断 |
| **导演 OS / 保真预算** | seedance-2.0 方法论层 | Allocation、事件密度、FLF | 无 Material Constitution 原语 | 吞进预算器 |
| **执行编排** | auvideo / 各类 agent pipeline | 真生成、真合成 | 不做深度导演交互 | 边界外，做下游客户 |
| **复刻管线** | autovidiocreator | URL→拆解→生成 | 目标是复刻，不是原创宪法 | 不做 |
| **静态摄影导演** | PerfectPhoto + NextShot | 交互、锁定域、名家静照 | 时间轴是桥不是主角 | **同构升维**（这是血缘优势） |

**关键判断：**  
GitHub 与公开 skill 里，**几乎没有**把下面四件同时焊死的产品：

1. 材质/世界宪法（不只是角色锁定）  
2. 时间码微事件表 + 因果 morph  
3. PerfectPhoto 级字面量跨镜锁（帽/道具归属/环境 full_text）  
4. 名家运镜**驱动矩阵**（不是影评散文）

这是空白战场。

---

## 2. 杀手锏：真正拉开身位的东西

按「不可轻易抄」排序。抄模板容易，抄**交互纪律 + 运行时闸门**难。

### 🥇 K1 · Material Constitution（材质宪法）—— 跨主体一致性的高一阶锁

**是什么：**  
不先锁「张三长什么样」，而先锁「这个世界所有人/物/建筑共用的流体语言」。  
一镜九人、服装发饰山石，**一次宪法**，不是九次 lock face。

**为什么是杀手锏：**  
- 竞品几乎只做 character bible，奇观世界一旦密度起来就炸  
- 样本级 prompt（流体雕塑）靠的是这一层，不是堆形容词  
- 把 Seedance「Identity 预算」从 9 人压到 **1 套物理语言 + N 个锚点**

**护城河深度：** ⭐⭐⭐⭐⭐  
（概念可抄，**交互里强制「先宪法后动作」+ 出镜 QC 拒无宪法稿** 才难抄）

---

### 🥇 K2 · 跨镜 Memory Pack（Bible + 字面量焊接 + Delta 白名单 + diff）

**是什么：**  
人物 / 帽饰独立字段 / 道具归属 / 环境 full_text / 氛围 / 光基线 / 材质宪法——  
**每镜全文拷贝，禁止「同上」；非法改装/换景拦截。**

**为什么是杀手锏：**  
- 用户感知最强的痛：「下一镜帽子没了」「三桌客人消失」  
- PerfectPhoto 已验；竞品多停在「记得用参考图」——参考图≠细节锁  
- NextShot 变成视频默认路径时，这是唯一能工业级连戏的底座

**护城河深度：** ⭐⭐⭐⭐⭐  
（规则纸面可抄，**Agent 强制 diff 闸门 + 环境禁摘要** 是工程纪律）

---

### 🥈 K3 · 15s 预算时间码 OS（微动表 + 焦点接力 + 世界驱动）

**是什么：**  
不是「写一段流畅动作」，而是：

- 0–3 / 3–6… 焦点接力（瞬时 identity≈1）  
- 人物只动一个子系统，静止写死  
- 环境流体/世界运动承担主视觉驱动  
- 可选 Timed Morph（动作后统一延迟/方向/速度）

**为什么是杀手锏：**  
- 直接回答「模型最多 15 秒」的工程现实  
- 竞品常堆同时发生的多大事 → 糊脸/穿模/运动糊  
- 与 Allocation（Identity / Motion / Scene density）同构，可科学拒稿

**护城河深度：** ⭐⭐⭐⭐

---

### 🥈 K4 · 三模式编译 + NextShot 一等公民

| 模式 | 竞争力点 |
|------|----------|
| Single15 | 一镜到底相位时间轴，世界观表演片 |
| MultiShot-in-one | 同次生成 Shot1/2/3 共享 lock 前缀 |
| NextShot Chain | 尾帧图 + 视频运动 prompt + **锁域含材质宪法** |

**为什么是杀手锏：**  
竞品常只会一种：要么单段散文，要么粗暴分镜列表。  
你同时支持**世界片**与**叙事连戏**，且编译合同不混（一镜合同 vs Shot-N 合同）。

**护城河深度：** ⭐⭐⭐⭐

---

### 🥉 K5 · 名家运镜矩阵（驱动，非散文）

**是什么：**  
≥16 名家卡：增强哪条基运镜、与谁冲突、预算偏置、签名短语、拦截条件。  
例：小津 + 「低角高速环绕」→ 拦截。

**为什么有杀伤力：**  
- PerfectPhoto 用户已习惯「选一个导演就对齐参数」  
- 公开 skill 多是「王家卫风格」四个字 → 模型乱演  
- 矩阵把审美变成**可执行的运镜/冲突表**

**护城河深度：** ⭐⭐⭐（可抄名单，难抄冲突表 + 与 transform 同构）

---

### 🥉 K6 · 交互人格（PerfectPhoto 同构）

**是什么：**  
意图编译 → 选择题引导 → 诊断/快速模式 → 反 AI 油腻 → 交付前自检。  
用户感觉是「跟导演开会」，不是「填空写 prompt」。

**为什么重要：**  
方法论再强，没有对话层就变成 research.md，落不了 skill 体验。  
这是对 PerfectPhoto 品牌心智的**迁移红利**——竞品没有这个血缘。

**护城河深度：** ⭐⭐⭐⭐（心智 + 流程，新竞品冷启动慢）

## 3. 什么「看起来像卖点」但不是杀手锏

| 伪卖点 | 为什么不够 |
|--------|------------|
| 更长的电影参数表（ARRI/Cooke/8K） | 词库一天就能堆满，且易油腻 |
| 负面提示词列表 | 人人有一份 |
| 单纯「分镜表 markdown」 | 没有 lock/delta 的分镜=多段抽卡 |
| 堆 50 个导演名字 | 无冲突矩阵 = 影评附加词 |
| 对接某个单一视频模型 API | 那是执行层，会被模型迭代冲掉 |

**铁律：** 可下载的静态 md 合集都不是护城河；**强制顺序 + 拒绝非法状态** 才是。

## 4. 还缺什么（按致命度排序）

### P0 · 不做会死 / 现在只有研究没有产品

| 缺口 | 说明 | 建议落点 |
|------|------|----------|
| **可运行 SKILL.md** | 研究齐了，用户还不能「打开就拍」 | `SKILL.md` + 主循环 S0–S12 |
| **Visual Bible / NextShotContext schema** | 协议有了，字段表未冻结成可 diff 的结构 | `schemas/lock-pack.json` 或 md 字段契约 |
| **Literal weld + diff 闸门** | 口头协议 ≠ Agent 每次真执行 | 输出前强制检查清单 + 禁止「同上」规则写死 |
| **Material presets 库（3–5 套）** | 宪法是概念，用户需要可选项 | 流体雕塑 / 水墨 / 青铜锈 / 玻璃空气 / 混凝土尘… |
| **三模式编译器规则** | Single / Multi / Chain 合同分离 | `references/compile-modes.md` |

### P1 · 有了才叫「视频大师」而不只是「一致性工具」

| 缺口 | 说明 |
|------|------|
| **声场锚点层** | 样本与多数输出几乎无声；CyberJ 要求 2–4 声锚；缺了缺临场感 |
| **节奏 / 呼吸合同** | World Breath 写在差异化里，尚无「BPM/相位/禁急停」可选项 |
| **Ensemble 舞台法** | 多人不合影、景层、焦点接力——需独立规则，防诊断器默认「只写 2–4 人」砍舞台 |
| **名家库正式文件** | research 有 16+ 卡，未落 `master-cinematography.md` + 与基运镜矩阵挂钩 |
| **平台 / 模型硬约束表** | 4–15s、画幅、是否支持首尾帧/多参考——编译器要吃 |
| **反油腻视频专版** | 静态 anti-slop ≠ 视频（禁随机喷溅、禁镜头炫技堆叠、禁参数炫耀） |

### P2 · 中长期才能形成壁垒

| 缺口 | 说明 |
|------|------|
| **实拍漂移清单** | 3–5 条真链实测：帽/道具/环境哪类描述最稳 | 没数据 = 锁定域权重拍脑袋 |
| **评分 / 诊断打回话术** | 预算超了怎么跟人说「砍哪一层」 | 导演感来自拒稿质量 |
| **与 auvideo 接口契约** | 下游执行怎么吃 lock-pack + prompt | 可选，保持边界清晰 |
| **多语言/中英对照编译** | 面向 Seedance / Kling / 国际工具 | 第二阶段 |
| **情绪-光-声 三联诊断** | 意图 → 光时间线 + 声场 + 微动作 自动对齐 | 高级导演模式 |

### 刻意不做（避免失去杀手锏焦点）

- 自动调用生成 API 跑片（auvideo 的活）  
- 对标视频 URL 复刻（autovidiocreator 的活）  
- 一万条运镜形容词库  
- 「一键大片」无诊断无预算

## 5. 竞争定位一句话（对内对外）

| 场景 | 话术 |
|------|------|
| **对用户** | 你不是在写提示词，你在冻结一个世界，再合法地运镜 15 秒。 |
| **对竞品** | 他们帮你「描述好看」；我们帮你「连戏不漂 + 预算不炸 + 宪法不散」。 |
| **对 PerfectPhoto 用户** | 同一套导演问答与锁定纪律，时间轴从可选桥变成主角；NextShot 升维。 |
| **对执行层** | PerfectVideo 产出可焊的 Bible + 合同 prompt；生成/剪辑另请编排器。 |

---

## 6. 护城河装配顺序（别并行冒烟）

若只能按序造 moat：

```
1) Lock Pack schema + 字面量焊接/diff     ← 先能连戏
2) Material Constitution + 3–5 presets   ← 先能世界级
3) 15s 时间码 + 三模式编译               ← 先能塞进模型
4) NextShot 闭环（含材质进锁域）         ← 先能长过 15s
5) 名家矩阵 + 冲突拦截                   ← 再上审美加速
6) 声场/呼吸/反油腻/平台表               ← 质感封顶
7) 实测漂移反馈改权重                    ← 科学化
```

**错误顺序：** 先堆 30 个导演 + 华丽示例 → 仍会跨镜漂、15s 炸，看起来像又一个词库。

## 7. 终局判断（视频大师口径）

**杀手锏不是「东方神话写得好」。**  
样板只证明了架构能装下世界级密度。

**真·杀手锏组合技：**

> **Material Constitution（世界怎么长一样）**  
> × **Memory Pack 字面量连戏（下一镜怎么不漂）**  
> × **15s 预算时间码（模型物理极限内怎么不炸）**  
> × **PerfectPhoto 级导演交互（人愿意跟着做完）**

**还缺的本质：**  
研究已经画出峰顶；缺的是 **可执行的锁与编译器**，不是更多形容词。  
缺文件，不缺方向。缺闸门，不缺灵感。

**一句话收束：**  
同类卖烟花；你要卖的是**片场法律**——宪法、预算、轴线、连戏。  
法律一旦写进 skill 运行时，词库系竞品只能继续卖烟花。
