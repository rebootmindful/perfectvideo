## 二、大导演视角审核（故事/情绪/机位/节奏/创新）

### 2.1 故事线与情绪 —— 方法论扎实，但有个隐患

**做对的**：
- 15 拍骨架（每拍改变观众理解）+ 开场↔终场视觉对照，是**真导演思维**不是词库堆砌。
- 情绪因果铁律（每个反应有可见触发）——江南 Shot2"见同貌→震惊→对视→抬手→指触"逐步升温，是标准戏剧节拍。

**隐患（导演视角最重要的一条）**：
> **没有"主角四问"的强制入口。** narrative-spine §1 定义了四问（想什么/怕什么/被什么压/错信什么），但 U0→UG 流程没有**强制**先答四问再出方向。演示中我们代填了，但 skill 规则上**允许跳过**——一旦跳过，方向选项就会退化成"好看的场景集合"而非"人物驱动的弧光"。
> **大导演会问**："这个女孩为什么要在船上？她怕什么？"——答不上来，片子就是氛围片不是剧情片。

### 2.2 机位与节奏 —— 光柱通道是真正的创新

- **光柱垂直通道**（江南 v2 发明）：把"高悬巨物 vs 藤蔓触水"的尺度矛盾，用一个"光柱=机位电梯"同时解决空间可走性+尺度自洽——**这是教科书级的导演解法**，值得写进机制库当案例。
- 25 条签名运镜 + 三档意图 + 预算联动，是**完整运镜体系**，不是形容词表。
- 节奏守门（≥2 动作/3s → 强制 A+）防止"单条塞爆"——正确。

### 2.3 创新性评分

| 创新点 | 独特性 | 行业对照 |
|---|---|---|
| Material Constitution（材质宪法） | ★★★★★ | 远超"风格关键词" |
| 光柱垂直通道（机位=叙事道具） | ★★★★★ | 少见 |
| 3 追问 NextShot 方向引擎 | ★★★★ | 优于"用户指哪打哪" |
| 出稿前六维审核（防合同自相矛盾） | ★★★★★ | 独有，实证救回 v4 |
| 双时长/三轨音频/双锚硬控制 | ★★★★ | 工程完整 |

## 三、大观众视角审核（看懂/不笑场/连贯）

### 3.1 实证：观众看得懂

江南两镜 29s：水乡孤女 → 巨物压顶 → 弦音共鸣 → 灵魂黑夜 → 光柱绽放 → 入内相认 → 指触传承。**全程无旁白可读**——这就是"show change, don't tell"的胜利。

### 3.2 实证：不笑场

- fast 版曾因机位瞬移/情绪断裂产生"搞笑感"——已被六维审核结构性拦截。
- v4/两镜拼合 MAD 检测无跳变尖峰，衔接平滑。

### 3.3 观众视角最大缺口

> **没有"观众测试"环节。** 出稿前审核是"导演自审"（防合同矛盾），但**没有模拟观众第一次看片的检查**：信息是否一次看懂？节奏是否太快？有没有"我猜不到但你也没解释"的断点？
> post-shot-review 是生成后对账（写拍改闭环），但**缺"试映"视角**——大导演会组织内部试映，这版 skill 没有。

## 四、First Shot → Next Shot 衔接审核（用户最关心）

### 4.1 逻辑衔接 —— 0.2.8 已正确

| 衔接点 | 机制 | 判定 |
|---|---|---|
| 叙事方向 | NG 门禁 3 追问 → 3 方向（A顺势/B换维/C反预期） | ✅ 真差异非换皮 |
| 人物/材质 | 字符级焊接继承（禁"同上"） | ✅ |
| 空间连续性 | 上镜尾帧 = 本镜首帧（物理锚） | ✅ |
| 光相位 | 基线继承 + 本镜内部重走弧线（江南：外部暖→内部冷→指触暖） | ✅ 杰作级 |
| 规则一致性 | 与 FirstShot 同链（审核/完整性/策略/对账/diff） | ✅ 用户要求已落实 |
| 全片时间线 | shotlist 跨镜连续时间码 | ✅ |

### 4.2 实证：两镜拼合无痕

- `jiangnan_2shots_combined.mp4`（29.41s）：xfade 0.8s 窗口帧差异 7-23（平滑），**因为 Shot2 首帧=Shot1 尾帧物理承接**，溶解只是润色。
- 两镜光相位形成**完整弧线**：Shot1 外部冷→暖（唤醒），Shot2 外部暖→内部冷→指触暖（相认）——**叙事弧跨镜连续**，不是两个独立短片。

### 4.3 衔接的 3 个薄弱点

| # | 薄弱点 | 风险 | 修复建议 |
|---|---|---|---|
| 1 | **视觉锚依赖文本继承** | 若上镜生成效果与文本有偏差（如脸型漂移），下镜首帧继承的是"偏差后的脸"，文本锁跟不上 | 每镜执行度对账时**必须比对"上镜尾帧实际 vs 文本锁"**，偏差>阈值 → 提示用户补一张 reference 图再进下镜 |
| 2 | **无"上镜尾帧质量"预检** | 尾帧若糊/构图差（如人物半出画），首帧锚直接带病 | NextShot 步骤 0 前加"尾帧可用性检查"（清晰度/主体在框/状态正确） |
| 3 | **跨镜光相位无全局对照** | 每镜内部弧线对，但**跨镜亮度/色温跳跃**无检查（如 Shot1 2K 暖 vs Shot2 720P 冷跳变） | 加"跨镜光相位桥"：下镜开场色温/亮度必须与上镜终场平滑过渡（模型约束内） |

## 五、系统性缺口（不修会成为天花板）

### 缺口 1：主角四问不是强制入口
**现状**：narrative-spine §1 有四问，但流程不强制。
**影响**：方向选项可能退化成"好看场景集合"。
**修法**：UG 门禁前置强制一步——出方向前先写"主角四问卡"（1 行/问），答不出就回 U0 追问。大导演视角这是**门槛不是负担**。

### 缺口 2：A+ MultiClip 逐拍模式断层
**现状**：A（单条）与 C（NextShot 链）都有完整链，但 **A+（多段逐拍）没有独立方法论文档**——运镜≥3 段或签名运镜时强制 A+，但 A+ 的"每拍独立 prompt + 尾帧接续 + xfade"如何做逻辑审核、如何保证逐拍连贯，只散落在 compile-modes。
**影响**：遇到复杂运镜诉求时执行质量取决于 agent 临场发挥。
**修法**：为 A+ 写独立流程（与 C 同规则：逐拍六维审核 + 尾帧链 + 对账）。

### 缺口 3：观众试映视角缺失
**现状**：导演自审有（六维），生成后对账有（post-shot），但**没有"模拟观众首次观看"**。
**修法**：出稿前审核加第 7 维"一次看懂"：不看 prompt 只看 shotlist 时间码，能否复述故事？信息密度是否超出 15s 认知负载？

## 七、建议落地优先级

| 优先级 | 动作 | 理由 |
|---|---|---|
| P0 | 主角四问强制卡（UG 前置） | 保证"人物驱动"而非"场景堆砌" |
| P0 | 上镜尾帧质量预检 + 实际 vs 文本偏差比对 | 防"带病锚点"跨镜传染 |
| P1 | 观众试映第 7 维（一次看懂） | 补齐大观众视角 |
| P1 | 跨镜光相位桥（开场接上镜终场） | 防跨镜跳变 |
| P2 | A+ 模式独立流程文档 | 消除模式断层 |
