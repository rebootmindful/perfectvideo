## 1. 验料结果（Skill 前提挑战）

**挑战 1 - 真实问题：成立。** AI 视频最大痛点是"下一镜漂"（人物/材质跨镜不一致）+"模型预算不懂成片必炸"（60s 需求塞一条 prompt）。PerfectVideo 用字面量焊接 + 双时长 + 首尾帧硬控制正面回答，且有 18 个真机 MP4 佐证。

**挑战 2 - 独特角度：方法论 + 工作流复合，无同质化。** 稀缺性来自三件同行都没有的东西：① **材质宪法**（统一材质语言全片锁定）② **出稿前七维逻辑审核**（防"导演合同自相矛盾"，实证见江南光相位逐秒复刻）③ **NextShot 3 追问方向引擎**（续镜给真实叙事差异非换皮）。本轮新访行 7 个 GitHub 同类，**无一做"跨镜连戏合同 + 出稿前审核"**。

**挑战 3 - 安装理由：成立。** 不是临时问 Agent"帮我写 prompt"，而是拿到一套**可连戏的导演合同**：锁定卡 + 分镜表 + verbatim 提示词 + 审核报告。装一次，每次出片都有方法论背书。

**挑战 4 - 公共传播性：有钩子、有产物，但产物露脸不足。** 钩子"别再让 AI 视频下一镜就漂了"锋利；可展示产物 18 真机 MP4 + 4 张 showcase 图（webp/jpg）真实存在——**但 showcase 图未嵌 README、MP4 被 gitignore 不在仓库可见层**，访客看不到。

**验料结论：好料，继续打磨。**

## 3. 生态位判断

**纵向**：从"提示词编译器"（0.1）→"艺术导演 OS + 连戏书记"（0.2）→ 正在走向"可验证的导演系统"（审核闸门 + 活体对账）。下一步该补"仓库可见层的可验证产物"（让 GitHub 访客亲眼看到成片）。

**横向**：同行立足点 = 大师背书（smixs）、钩子增长（rediumvex）、全案文件（zxz233301）、模型矩阵（IMA Studio）。**没有人立"连戏 + 审核"这个位。**

**交叉洞察**：该抢的生态位不是"更漂亮的提示词"，而是 **"AI 视频唯一带锁的导演 OS"**——锁 = 跨镜字面量焊接 + 出稿前七维审核 + 活体对账。同行卖"生成"，我们卖"合同 + 可验证"。

**一句话新定位**：*「AI 视频唯一带锁的导演 OS：跨镜不漂、合同自洽、真机可验。」*

## 5. 差距清单

### P0：不补就无法公开/无法信任
- ✅ 已无（0.2.9 全链闭环 + LICENSE + .gitignore 焊死 outputs/密钥）

### P1：补上后明显提升安装率/传播率/可信度
- **活体证据不在仓库可见层**：`outputs/`（18 MP4）被 gitignore，GitHub 访客看不到最强卖点。建议：① 提交 1–2 个精简 sample 成片（如江南两镜 29s 压到 ≤10MB）进 `examples/showcase/` 并直链；或 ② 把产物托管后 README 嵌外链；或 ③ README 明确写"证据在本地 outputs/，仓库不含大文件"。
- **showcase 图未嵌 README**：`examples/showcase/` 有 4 张真机对比图（v1 vs v3、seam 接缝、demo），README 完全没引用。首屏应直接贴 demo_v3.webp + compare_v1_vs_v3.jpg。
- **缺 30s 端到端 GIF**：输入文案 → 成片的最短动图，是视频类 Skill 降低认知门槛的标配（同行 IMA Studio / SkillMD 都用）。

### P2：锦上添花
- `evals/trigger_cases.json` 版本号 0.2.1 → 改 0.2.9（顺手）
- `.claude-plugin/marketplace.json` 缺失（ClawHub 市场元数据，提升分发渠道发现率）

3. **光相位/材质宪法可验证细节**——江南光相位逐秒复刻，是最硬的可信度锤

## 6. 三个打磨方向

### 方案 A：细修——仓库可见层对齐（零风险）
新定位：不变。把"证据在仓里但访客看不到"的缺口补上。
改动范围：① README 嵌入 `examples/showcase/` 的 demo_v3.webp + compare_v1_vs_v3.jpg ② `evals` 版本 0.2.1→0.2.9 ③ 加一句"证据在本地 outputs/，仓库不含大文件" ④ README 注明"纯方法论 skill 无 scripts"。
优点：零风险、立刻可发、直接修复 P1 的"图未嵌"与 P2。
风险：无。
适合：本轮首选安全动作。

### 方案 B：精雕——可验证 show + GIF（传播质变）
新定位：不变，增加"首屏 10 秒想看"的视觉冲击与仓库可验证产物。
改动范围：① 提交 1–2 个 sample 成片（压 ≤10MB）进 `examples/showcase/` 并直链 ② 录 30s GIF（输入文案→成片）③ 写 `.tape` 录制脚本入库 ④ 加 `marketplace.json`。
优点：传播力 + 可信度质变，直击 P1 活体可见性。
风险：GIF 录制 + 压片耗时；sample 成片需确认版权/体积。
适合：A 完成后。

### 方案 C：开套件——拆出独立 `video-logic-audit` skill
新定位：PerfectVideo（导演 OS）+ 独立 `video-logic-audit`（七维审核闸门）双 skill。
改动范围：新增子 skill，把 `references/pre-submit-logic-audit.md` 抽成可独立调用的审核器。
优点：审核能力独立可复用（任何视频 prompt 都能过一遍）。
风险：超出本轮范围、增加维护面、需重新设计触发。
适合：后续版本。

**推荐：方案 A 先行（零风险闭环 P1 图未嵌 + P2 版本号），随即方案 B 冲传播与可信度。方案 C 留待下一轮。**
